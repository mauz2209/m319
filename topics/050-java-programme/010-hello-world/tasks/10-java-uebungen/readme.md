# Erste Schritte in Java
## Ziel

* Du lernst erste Befehle in Java zu schreiben.

## Auftrag

Wähle beliebige [Übungen](https://www.w3resource.com/java-exercises/basic/index.php) aus, programmiere sie in IntelliJ und prüfe ihre Lösung selbst.

## Form

* Einzelarbeit

## Zeit

* 30 Minuten

## Auswertung

* Selbständig überprüfen, ob die Übungen korrekt in Java programmiert wurden und die Lösungen stimmen.
