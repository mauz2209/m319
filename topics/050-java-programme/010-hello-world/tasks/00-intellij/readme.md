# IntelliJ IDEA installieren
## Ziel

* Du kannst IntelliJ IDEA auf deinem Computer installieren und starten.
* Du hast eine Education License für die IntelliJ IDEA aktiviert.

## Auftrag

Installiere IntelliJ IDEA auf deinem Computer, erstelle einen JetBrains-Account und aktiviere die Education License.  
Im [README](../../readme.md) findest du die Schritte dazu.

## Resultat

* Eine funktionierende Installation von IntelliJ IDEA mit aktivierter Education License.

## Form

* Einzelarbeit

## Zeit

* 30 Minuten

## Auswertung

* Selbständig überprüfen, ob IntelliJ IDEA korrekt installiert ist und die Education License aktiviert wurde.
