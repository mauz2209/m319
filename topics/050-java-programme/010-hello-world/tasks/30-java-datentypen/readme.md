# Datentypen in Java
## Ziel

* Du übst, verschiedene Datentypen in Java anzuwenden.

## Auftrag

Erstellen Sie ein einfaches Taschenrechner-Programm, das Folgendes macht: 
* Bitten Sie den Benutzer, zwei Zahlen einzugeben (beide können Ganzzahlen oder Dezimalzahlen sein).
* Bitten Sie den Benutzer, eine grundlegende arithmetische Operation auszuwählen (+, -, *, /).
* Führen Sie die Operation durch und zeigen Sie das Ergebnis an.
* Verwenden Sie eine boolean-Variable, um zu steuern, ob der Benutzer weitere Berechnungen durchführen oder das Programm beenden möchte.  

Eine Beispielausgabe des Taschenrechners könnte wie folgt aussehen:

```
Geben Sie die erste Zahl ein: 5
Geben Sie die zweite Zahl ein: 2
Wählen Sie eine Operation (+, -, *, /): +
Ergebnis: 7.0
Möchten Sie eine weitere Berechnung durchführen? (y/n): y

Geben Sie die erste Zahl ein: 10.5
Geben Sie die zweite Zahl ein: 4.5
Wählen Sie eine Operation (+, -, *, /): *
Ergebnis: 47.25
Möchten Sie eine weitere Berechnung durchführen? (y/n): n

Auf Wiedersehen!
```

Das template eines Java-Programms für diesen Taschenrechner liegt im Ordner [java-programme](../../../../../java-projekte/calculator).

## Resultat

* Ein Taschenrechner-Programm, das in IntelliJ ausgeführt werden kann.
