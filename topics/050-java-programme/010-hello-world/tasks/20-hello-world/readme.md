# Hello World als Java-Programm
## Ziel

* Du kannst in IntelliJ ein Java-Programm erstellen, kompilieren und ausführen.

## Auftrag

Du sollst ein möglichst einfaches Programm erstellen. Dazu gehen Sie wie folgt vor: 
1. Lies im [Script](../../script.md) nach, was ein "Hello World Programm" ist.
2. Installiere IntelliJ.
3. Erstelle ein HelloWorld-Programm in IntelliJ und starte es.

## Resultat

* Ein 'Hello-World'-Programm, das in IntelliJ ausgeführt werden kann.

## Form

* Einzelarbeit

## Zeit

* 30 Minuten

## Auswertung

* Zeige dein Programm der LP.
