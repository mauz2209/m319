# Ein Programm in Java mit GUI
## Ziel

* Du lernst, einfache GUI-Elemente mit einem Java-GUI Framework zu erstellen.

## Auftrag

Du sollst selbständig erlernen, wie du mit Java GUI-Elemente erstellst. Die einfachste Anwendung ist, einen Text innerhalb eines "Fensters" anzuzeigen.
Du bist frei darin, andere Anwendungen auszudenken und zu implementieren.
* Stelle einer KI die Frage: "how can i create a gui element with java with only a few lines of code"
* Erstelle dann ein neues Projekt in IntelliJ. Im Dialog "neues Projekt" wähle die packages aus, die du für dein GUI brauchst (z.B. das package "swing").
* Erstelle deine Applikation. Starte im main().
* 
## Resultat

* Ein 'Hello-World'-Programm, das in IntelliJ ausgeführt werden kann.

## Form

* Einzelarbeit

## Zeit

* 90 Minuten

## Auswertung

* Zeige dein Programm der LP.
