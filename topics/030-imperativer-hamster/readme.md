# Imperativer Hamster

Mit dem imperativen Hamster lernen wir die wichtigsten Grundlagen der Programmierung.

Wir steuern einen Hamster durch ein Territorium.

Der Hamster kann sich bewegen, Körner aufnehmen und Körner ablegen.

Aus diesen einfachen Möglichkeiten entstehen Schritt für Schritt komplexere Programme.

## Imperative Programmierung

Bei der imperativen Programmierung beschreiben wir mit Anweisungen, **was der Computer tun soll**.

Ein einfaches Hamster-Programm kann beispielsweise so aussehen:

~~~java
void main() {
    vor();
    vor();
    nimm();
}
~~~

Die Anweisungen werden der Reihe nach ausgeführt.

Der Hamster geht zwei Schritte vorwärts und nimmt danach ein Korn auf.

Im Verlauf der Aufgaben lernen wir weitere Möglichkeiten kennen.

Wir können Entscheidungen treffen.

Wir können Anweisungen wiederholen.

Wir können Werte speichern.

Wir können eigene Funktionen schreiben.

## Aufgaben bearbeiten

Zu jedem Thema findest du mehrere Aufgaben.

Für jede Hamster-Aufgabe erstellst du einen eigenen Ordner unter:

~~~text
/hamster-sim/Programme
~~~

Der Name des Ordners steht in der jeweiligen Aufgabe.

Zu einer Aufgabe gehören normalerweise:

- dein Hamster-Programm,
- das Territorium,
- die erzeugte Java-Datei.

Teste dein Programm mit dem Hamster-Simulator.

Achte darauf, dass dein Programm auch mit den in der Aufgabe beschriebenen Veränderungen des Territoriums funktioniert.

## Schritt für Schritt

Versuche nicht, eine Aufgabe sofort vollständig zu lösen.

Zerlege das Problem zuerst in kleinere Teile.

Teste diese Teile einzeln.

Wenn ein Teil funktioniert, baust du darauf weiter.

So kannst du Fehler leichter finden und verstehen.
