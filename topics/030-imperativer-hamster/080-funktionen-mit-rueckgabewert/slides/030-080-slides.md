# Funktionen mit Rückgabewert

## Bisher

Mit Parametern können wir einer Funktion Werte **übergeben**.

```java
void gehe(int anzahl) {
    for (int i = 0; i < anzahl; i++) {
        vor();
    }
}
```

Manchmal soll eine Funktion aber auch einen Wert **zurückgeben**.

## Rückgabewert

Eine Funktion kann ein Ergebnis berechnen und zurückgeben.

```java
int doppelt(int zahl) {
    return zahl * 2;
}
```

`int` gibt den **Datentyp des Rückgabewerts** an.

`return` gibt das Ergebnis zurück.

## Rückgabewert verwenden

Den Rückgabewert können wir in einer Variable speichern:

```java
int ergebnis = doppelt(5);
```

Danach gilt:

```text
ergebnis = 10
```

Oder wir verwenden ihn direkt:

```java
gehe(doppelt(3));
```

## `void` oder Rückgabewert? (1 / 2)

Eine Funktion ohne Rückgabewert:

```java
void rechtsUm() {
    linksUm();
    linksUm();
    linksUm();
}
```

`void` bedeutet:

**Die Funktion gibt keinen Wert zurück.**

## `void` oder Rückgabewert? (2 / 2)

Eine Funktion mit Rückgabewert:

```java
int doppelt(int zahl) {
    return zahl * 2;
}
```

`int` bedeutet:

**Die Funktion gibt eine ganze Zahl zurück.**

`return` gibt den Wert an die aufrufende Stelle zurück.

## Parameter und Rückgabewert

Eine Funktion kann Werte erhalten und ein Ergebnis zurückgeben:

```java
int addiere(int a, int b) {
    return a + b;
}
```

Aufruf:

```java
int summe = addiere(3, 4);
```

```text
3 und 4
   ↓
addiere()
   ↓
   7
```

## Merken

Parameter gehen **in die Funktion hinein**.

Ein Rückgabewert kommt **aus der Funktion heraus**.

```text
Parameter
   ↓
Funktion
   ↓
Rückgabewert
```

```java
int addiere(int a, int b) {
    return a + b;
}
```

**Eine Funktion mit Rückgabewert liefert ein Ergebnis, das im Programm weiterverwendet werden kann.**
