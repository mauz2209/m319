# Aufgabe – Zähle die Körner

Auf dem Startfeld des Hamsters liegt eine unbekannte Anzahl Körner.

![Territorium Zähle die Körner](../../../../../img/030-080-01-zaehle-die-koerner-ter.png)

Der Hamster soll alle Körner aufnehmen und zählen.

Das Zählen soll eine Funktion übernehmen, welche die Anzahl der Körner zurückgibt.

Danach soll der Hamster für jedes gezählte Korn genau einen Schritt vorwärtsgehen.

## Lernziel

Ich kann eine Funktion mit dem Rückgabetyp `int` erstellen, die eine unbekannte Anzahl Körner zählt und das Ergebnis mit `return` zurückgibt.

## Auftrag

1. Erstelle den Ordner `030-080-01-zaehle-die-koerner` im Ordner `/hamster-sim/Programme`.
2. Erstelle das vorgegebene Territorium mit dem Hamster-Simulator und speichere es.
3. Erstelle eine Funktion `int zaehleKoerner()`.
4. Die Funktion soll alle Körner auf dem aktuellen Feld aufnehmen und zählen.
5. Gib die gezählte Anzahl mit `return` zurück.
6. Rufe `zaehleKoerner()` in `main()` auf.
7. Speichere den Rückgabewert in einer Variable.
8. Gehe danach für jedes gezählte Korn genau einen Schritt vorwärts.
9. Teste dein Programm mit unterschiedlichen Anzahlen Körner auf dem Startfeld.

Dein Programm ist fertig, wenn die Funktion die Anzahl Körner zurückgibt und der Hamster danach für jedes aufgenommene Korn genau einen Schritt geht.
