# Aufgabe – Baue Körner-Haufen

Der Hamster hat genügend Körner im Maul.

Vor ihm liegen mehrere Felder.

![Territorium Baue Körner-Haufen](../../../../../img/030-070-02-baue-koerner-haufen-ter.png)

Der Hamster soll auf diesen Feldern unterschiedlich grosse Körner-Haufen bauen.

Dafür soll dieselbe Funktion mit unterschiedlichen Argumenten verwendet werden.

## Lernziel

Ich kann eine Funktion mit einem `int`-Parameter definieren und dieselbe Funktion mit unterschiedlichen Argumenten aufrufen, um verschieden grosse Körner-Haufen zu bauen.

## Auftrag

1. Erstelle den Ordner `030-070-02-baue-koerner-haufen` im Ordner `/hamster-sim/Programme`.
2. Erstelle das vorgegebene Territorium mit dem Hamster-Simulator und speichere es.
3. Erstelle eine Funktion `baueHaufen(int anzahl)`.
4. Der Parameter `anzahl` bestimmt, wie viele Körner der Hamster auf dem aktuellen Feld ablegt.
5. Verwende in der Funktion eine `for`-Schleife zum Ablegen der Körner.
6. Baue nacheinander Körner-Haufen mit `2`, `5`, `3`, `6` und `4` Körnern.
7. Rufe dafür immer dieselbe Funktion `baueHaufen()` auf.
8. Übergib die gewünschte Anzahl Körner jeweils als Argument.
9. Gehe nach jedem Körner-Haufen zum nächsten Feld.
10. Teste dein Programm im Hamster-Simulator.

Dein Programm ist fertig, wenn auf den fünf Feldern nacheinander Körner-Haufen mit `2`, `5`, `3`, `6` und `4` Körnern liegen.

Die Funktion `baueHaufen(int anzahl)` darf nur einmal definiert werden.
