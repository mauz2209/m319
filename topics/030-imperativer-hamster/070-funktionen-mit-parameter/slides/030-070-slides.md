# Funktionen mit Parameter

## Bisher

Eine Funktion führt immer dieselben Anweisungen aus.

```java
void rechtsUm() {
    linksUm();
    linksUm();
    linksUm();
}
```

Was aber, wenn wir einer Funktion einen **Wert mitgeben** möchten?

## Parameter

Ein Parameter ist eine Information, die wir einer Funktion beim Aufruf übergeben.

```java
void gehe(int anzahl) {
    for (int i = 0; i < anzahl; i++) {
        vor();
    }
}
```

`anzahl` ist der Parameter.

Die Funktion kann dadurch mit unterschiedlichen Werten arbeiten.

## Funktion aufrufen

Beim Aufruf übergeben wir einen Wert:

```java
gehe(3);
```

Der Hamster geht 3 Felder.

```java
gehe(7);
```

Der Hamster geht 7 Felder.

**Dieselbe Funktion kann für unterschiedliche Werte verwendet werden.**

## Mehrere Parameter

Eine Funktion kann mehrere Parameter besitzen.

```java
void geheUndGib(int schritte, int koerner) {
    for (int i = 0; i < schritte; i++) {
        vor();
    }

    for (int i = 0; i < koerner; i++) {
        gib();
    }
}
```

Aufruf:

```java
geheUndGib(4, 2);
```

Die Reihenfolge der Werte entspricht der Reihenfolge der Parameter.

## Merken

Parameter machen Funktionen **flexibler**.

```java
void gehe(int anzahl) {
    // ...
}
```

Aufruf:

```java
gehe(5);
```

`int anzahl` → **Parameter**

`5` → übergebener **Wert**

**Wir schreiben eine Funktion einmal und verwenden sie mit unterschiedlichen Werten.**
