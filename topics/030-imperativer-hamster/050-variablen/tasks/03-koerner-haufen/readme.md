# Aufgabe – Körner-Haufen

Auf mehreren Feldern liegen unterschiedlich viele Körner.

![Territorium Körner-Haufen](../../../../../img/030-050-03-koerner-haufen-ter.png)

Der Hamster weiss nicht, auf welchem Feld die meisten Körner liegen.

Er soll den grössten Körner-Haufen finden und alle Körner dieses Haufens aufnehmen.

## Lernziel

Ich kann mit Variablen die Anzahl Körner auf verschiedenen Feldern zählen und vergleichen, um das Feld mit der grössten Anzahl Körner zu bestimmen.

## Auftrag

1. Erstelle den Ordner `030-050-03-koerner-haufen` im Ordner `/hamster-sim/Programme`.
2. Erstelle das vorgegebene Territorium mit dem Hamster-Simulator und speichere es.
3. Programmiere den Hamster so, dass er die Anzahl Körner auf den einzelnen Feldern selbst bestimmt.
4. Verwende eine Variable, um die Anzahl Körner eines Haufens zu zählen.
5. Verwende eine weitere Variable, um die bisher grösste Anzahl Körner zu speichern.
6. Vergleiche die Körner-Haufen miteinander.
7. Bestimme das Feld mit der grössten Anzahl Körner.
8. Der Hamster soll am Ende alle Körner des grössten Haufens aufnehmen.
9. Teste dein Programm im Hamster-Simulator.
10. Verändere die Anzahl Körner auf den Feldern und teste dein Programm erneut.

Dein Programm ist fertig, wenn der Hamster den grössten Körner-Haufen selbst findet und alle Körner dieses Haufens aufnimmt.

Das Programm soll auch funktionieren, wenn die Anzahl Körner auf den einzelnen Feldern verändert wird.
