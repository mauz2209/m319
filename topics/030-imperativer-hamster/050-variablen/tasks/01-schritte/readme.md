# Aufgabe – Schritte zählen

Auf dem Startfeld des Hamsters liegt eine unbekannte Anzahl Körner.

![Territorium Schritte](../../../../../img/030-050-01-schritte-ter.png)

Der Hamster soll zuerst alle Körner aufnehmen und dabei zählen.

Für jedes aufgenommene Korn soll er danach genau einen Schritt vorwärtsgehen.

Dabei darf der Hamster nicht gegen eine Mauer laufen.

## Lernziel

Ich kann mit einer Variable die Anzahl aufgenommener Körner zählen und diesen Wert verwenden, um den Hamster entsprechend viele Schritte vorwärtsgehen zu lassen, ohne gegen eine Mauer zu laufen.

## Auftrag

1. Erstelle den Ordner `030-050-01-schritte` im Ordner `/hamster-sim/Programme`.
2. Erstelle das vorgegebene Territorium mit dem Hamster-Simulator und speichere es.
3. Erstelle eine Variable für die Anzahl Körner.
4. Der Hamster soll alle Körner auf seinem Startfeld aufnehmen.
5. Erhöhe die Variable für jedes aufgenommene Korn um `1`.
6. Verwende eine `while`-Schleife zum Zählen und Aufnehmen der Körner.
7. Danach soll der Hamster für jedes gezählte Korn einen Schritt vorwärtsgehen.
8. Prüfe vor jedem Schritt mit `vornFrei()`, ob der Hamster weitergehen kann.
9. Der Hamster darf nicht gegen eine Mauer laufen.
10. Teste dein Programm auch mit einer anderen Anzahl Körner auf dem Startfeld.

Dein Programm ist fertig, wenn der Hamster für jedes gezählte Korn einen Schritt gegangen ist oder vor einer Mauer stehen geblieben ist.
