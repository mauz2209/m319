# Variablen

## Werte speichern

Ein Programm muss sich manchmal etwas **merken**.

Beispiel:

Der Hamster sammelt Körner und soll zählen, wie viele er gefunden hat.

Dafür verwenden wir eine **Variable**.

## Eine Variable

Eine Variable hat einen **Namen**, einen **Datentyp** und einen **Wert**.

```java
int anzahl = 0;
```

```text
int      Datentyp
anzahl   Name
0        Wert
```

`int` steht für eine ganze Zahl.

## Werte verändern

Den Wert einer Variable können wir verändern.

```java
int anzahl = 0;

anzahl = anzahl + 1;
```

Danach hat `anzahl` den Wert `1`.

Bei jedem weiteren:

```java
anzahl = anzahl + 1;
```

wird der Wert um eins erhöht.

## Körner zählen

Variablen lassen sich mit unseren bisherigen Kontrollstrukturen kombinieren.

```java
int anzahl = 0;

while (vornFrei()) {
    vor();

    if (kornDa()) {
        nimm();
        anzahl = anzahl + 1;
    }
}
```

`anzahl` speichert, wie viele Körner der Hamster aufgenommen hat.

## Wert verwenden

Den gespeicherten Wert können wir später wieder verwenden.

```java
while (anzahl > 0) {
    gib();
    anzahl = anzahl - 1;
}
```

Die Variable verändert damit das Verhalten des Programms.

## Merken

Eine Variable speichert einen Wert unter einem Namen.

```java
int anzahl = 0;
```

Der Wert kann gelesen und verändert werden:

```java
anzahl = anzahl + 1;
anzahl = anzahl - 1;
```

**Variablen geben einem Programm ein Gedächtnis.**
