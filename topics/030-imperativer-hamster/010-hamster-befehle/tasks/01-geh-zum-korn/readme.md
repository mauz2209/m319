# Aufgabe – Geh zum Korn

Der Hamster befindet sich in einem einfachen Territorium.

![Territorium Geh zum Korn](../../../../../img/030-010-01-geh-zum-korn-ter.png)

Am Ende des Weges liegt ein Korn.

## Lernziel

Ich kann den Hamster mit den Grundbefehlen `vor()`, `linksUm()` und `nimm()` zu einem Korn führen und das Korn aufnehmen.

## Auftrag

1. Öffne das vorgegebene Territorium.
2. Programmiere den Hamster so, dass er dem Weg folgt.
3. Der Hamster soll das Korn am Ende des Weges aufnehmen.
4. Verwende nur die Befehle `vor()`, `linksUm()` und `nimm()`.
5. Teste dein Programm im Hamster-Simulator.

Dein Programm ist fertig, wenn der Hamster das Korn aufgenommen hat.
