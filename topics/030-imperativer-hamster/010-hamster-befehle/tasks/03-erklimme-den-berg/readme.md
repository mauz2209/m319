# Aufgabe – Erklimme den Berg

Der Hamster steht vor einem Berg mit mehreren Stufen.

![Territorium Erklimme den Berg](../../../../../img/030-010-03-erklimme-den-berg-ter.png)

Auf dem Gipfel liegt ein Korn.

## Lernziel

Ich kann den Hamster mit den Grundbefehlen `vor()`, `linksUm()` und `nimm()` über mehrere Stufen eines vorgegebenen Territoriums steuern und das Korn auf dem Gipfel aufnehmen.

## Auftrag

1. Erstelle den Ordner `030-010-03-erklimme-den-berg` im Ordner `/hamster-sim/Programme`.
2. Erstelle das vorgegebene Territorium mit dem Hamster-Simulator und speichere es.
3. Programmiere den Hamster so, dass er den Berg Stufe für Stufe erklimmt.
4. Der Hamster darf nicht gegen eine Mauer laufen.
5. Der Gipfel ist das Feld, auf dem das Korn liegt.
6. Nimm das Korn auf dem Gipfel auf.
7. Verwende nur die Befehle `vor()`, `linksUm()` und `nimm()`.
8. Teste dein Programm im Hamster-Simulator.

Dein Programm ist fertig, wenn der Hamster auf dem Gipfel steht und das Korn aufgenommen hat.
