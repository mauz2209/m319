# Imperativer Hamster

## Der Hamster-Simulator

Wir programmieren einen Hamster in einer einfachen Welt.

Der Hamster kann nur wenige Befehle ausführen.

Damit lernen wir die Grundlagen des **imperativen Programmierens**.

## Die Hamster-Welt

Die Welt besteht aus:

* **Feldern**
* **Mauern**
* **Körnern**
* einem **Hamster**

Der Hamster steht auf einem Feld und schaut in eine bestimmte Richtung.

## Die vier Befehle

Der Hamster versteht vier grundlegende Befehle:

```java
vor();
linksUm();
nimm();
gib();
```

| Befehl | Wirkung |
| --- | --- |
| `vor()` | ein Feld vorwärts |
| `linksUm()` | 90° nach links drehen |
| `nimm()` | ein Korn aufnehmen |
| `gib()` | ein Korn ablegen |

## Befehle nacheinander ausführen

Der Hamster führt die Befehle **von oben nach unten** aus.

```java
vor();
vor();
linksUm();
vor();
nimm();
```

Die **Reihenfolge** der Befehle bestimmt das Verhalten.

## Auftrag

Löst die ersten Hamster-Aufgaben:

1. **Geh zum Korn**
2. **Sammle die Körner**
3. **Erklimme den Berg**

Verwendet zunächst nur die vier Hamster-Befehle.

## Auswertung

Was passiert bei diesem Programm?

```java
vor();
vor();
linksUm();
vor();
nimm();
```

Wir können den Ablauf Schritt für Schritt nachvollziehen.

**Programmieren bedeutet hier: Dem Hamster eine eindeutige Folge von Anweisungen geben.**
