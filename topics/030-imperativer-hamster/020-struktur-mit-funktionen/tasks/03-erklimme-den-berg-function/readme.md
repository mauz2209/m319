# Aufgabe – Erklimme den Berg mit Funktionen

Du kennst die Aufgabe **Erklimme den Berg** bereits.

Verwende dasselbe Territorium noch einmal.

![Territorium Erklimme den Berg](../../../../../img/030-010-03-erklimme-den-berg-ter.png)

Beim Erklimmen des Berges wiederholen sich ähnliche Befehlsfolgen.

Diese Wiederholungen eignen sich gut für eigene Funktionen.

## Lernziel

Ich kann eine wiederkehrende Bewegungsfolge beim Erklimmen eines Berges erkennen, in eine eigene Funktion auslagern und diese Funktion mehrfach in `main()` verwenden.

## Auftrag

1. Erstelle den Ordner `030-020-03-erklimme-den-berg-function` im Ordner `/hamster-sim/Programme`.
2. Verwende das Territorium aus der Aufgabe **Erklimme den Berg**.
3. Übernimm deine bisherige Lösung als Ausgangspunkt.
4. Erstelle eine eigene Funktion `rechtsUm()`.
5. Untersuche den Ablauf beim Erklimmen einer einzelnen Stufe.
6. Fasse die Befehle für eine Stufe in einer eigenen Funktion zusammen.
7. Gib dieser Funktion einen passenden Namen.
8. Rufe diese Funktion in `main()` mehrfach auf.
9. Nimm das Korn auf dem Gipfel auf.
10. Teste dein Programm im Hamster-Simulator.

Dein Programm ist fertig, wenn der Hamster auf dem Gipfel steht und das Korn aufgenommen hat.

`main()` soll den Ablauf des Programms klar zeigen.

Die einzelnen Schritte zum Erklimmen einer Stufe sollen in einer eigenen Funktion stehen.
