# Struktur mit Funktionen

## Ein bekanntes Problem

Der Hamster kann sich nur nach links drehen.

Für eine Drehung nach rechts brauchen wir deshalb drei Befehle:

```java
linksUm();
linksUm();
linksUm();
```

Brauchen wir das mehrmals, wiederholen wir immer wieder dieselben Befehle.

## Eigene Befehle

Wir können mehrere Befehle zu einer **Funktion** zusammenfassen:

```java
void rechtsUm() {
    linksUm();
    linksUm();
    linksUm();
}
```

Danach können wir unseren neuen Befehl verwenden:

```java
vor();
rechtsUm();
vor();
```

## Eine Funktion

Eine Funktion hat einen **Namen** und einen **Funktionskörper**:

```java
void rechtsUm() {
    linksUm();
    linksUm();
    linksUm();
}
```

`rechtsUm` ist der Name der Funktion.

Zwischen `{` und `}` stehen die Anweisungen der Funktion.

## Funktion aufrufen

Die Definition der Funktion beschreibt, **was sie macht**.

```java
void rechtsUm() {
    linksUm();
    linksUm();
    linksUm();
}
```

Der Aufruf führt die Funktion aus:

```java
rechtsUm();
```

Eine Funktion kann beliebig oft aufgerufen werden.

## Programme strukturieren

Ohne eigene Funktionen:

```java
vor();
linksUm();
linksUm();
linksUm();
vor();
linksUm();
linksUm();
linksUm();
vor();
```

Mit einer Funktion:

```java
vor();
rechtsUm();
vor();
rechtsUm();
vor();
```

Der Ablauf wird **kürzer und verständlicher**.

## Gute Funktionen

Eine Funktion fasst Anweisungen zusammen, die gemeinsam eine **Aufgabe** erledigen.

```java
rechtsUm();
```

ist verständlicher als:

```java
linksUm();
linksUm();
linksUm();
```

Ein guter Funktionsname beschreibt, **was die Funktion macht**.

## Auswertung

Eigene Funktionen helfen uns:

* Wiederholungen zu vermeiden.
* Programme zu strukturieren.
* die Absicht des Programms sichtbar zu machen.
* Änderungen an einer Stelle vorzunehmen.

**Wir bauen aus einfachen Befehlen neue, mächtigere Befehle.**
