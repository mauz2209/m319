# While-Schleifen

## Ein bekanntes Problem

Der Hamster soll bis zur Mauer laufen.

Wir könnten schreiben:

```java
vor();
vor();
vor();
vor();
vor();
```

Das funktioniert aber nur, wenn wir vorher wissen, **wie weit die Mauer entfernt ist**.

## Wiederholen, solange ...

Mit einer `while`-Schleife wiederholen wir Anweisungen, **solange eine Bedingung erfüllt ist**.

```java
while (vornFrei()) {
    vor();
}
```

Solange vorne frei ist, läuft der Hamster weiter.

## Ablauf einer `while`-Schleife

```text
       vornFrei()?
        /       \
     true       false
      |           |
    vor()       weiter
      |
      └───────────┐
                  |
            erneut prüfen
```

Die Bedingung wird **vor jedem Durchlauf** geprüft.

## `while` und `if`

`if` entscheidet **einmal**:

```java
if (kornDa()) {
    nimm();
}
```

`while` prüft die Bedingung **immer wieder**:

```java
while (kornDa()) {
    nimm();
}
```

So kann der Hamster alle Körner auf einem Feld aufnehmen.

## Achtung: Endlosschleife

Die Schleife muss irgendwann enden können.

```java
while (vornFrei()) {
    linksUm();
}
```

`linksUm()` verändert nicht, ob vorne eine Mauer steht.

Die Bedingung kann deshalb immer `true` bleiben.

**Das Programm läuft endlos weiter.**

## Merken

Eine `while`-Schleife wiederholt Anweisungen, solange eine Bedingung `true` ist.

```java
while (Bedingung) {
    Anweisungen;
}
```

Wir verwenden `while`, wenn wir **nicht vorher wissen, wie oft** etwas wiederholt werden muss.
