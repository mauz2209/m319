# Aufgabe – Körner-Runden

Auf dem Startfeld des Hamsters liegen mehrere Körner.

![Territorium Körner-Runden](../../../../../img/030-040-03-koerner-runden-ter.png)

Für jedes Korn soll der Hamster eine vollständige Runde drehen.

Nach jeder Runde nimmt er ein Korn auf.

Wenn keine Körner mehr auf dem Startfeld liegen, bleibt der Hamster stehen.

## Lernziel

Ich kann mit einer `while`-Schleife einen Ablauf für jedes vorhandene Korn wiederholen, bis auf dem Startfeld kein Korn mehr liegt.

## Auftrag

1. Erstelle den Ordner `030-040-03-koerner-runden` im Ordner `/hamster-sim/Programme`.
2. Erstelle das vorgegebene Territorium mit dem Hamster-Simulator und speichere es.
3. Erstelle eine eigene Funktion, mit welcher der Hamster eine vollständige Runde dreht.
4. Der Hamster soll nach jeder Runde wieder auf seinem Startfeld stehen.
5. Prüfe mit `kornDa()`, ob auf dem Startfeld noch ein Korn liegt.
6. Solange ein Korn da liegt, soll der Hamster eine Runde drehen und danach ein Korn aufnehmen.
7. Verwende dafür eine `while`-Schleife.
8. Wenn keine Körner mehr auf dem Startfeld liegen, soll der Hamster stehen bleiben.
9. Teste dein Programm im Hamster-Simulator.

Dein Programm ist fertig, wenn der Hamster für jedes Korn genau eine Runde gedreht und alle Körner aufgenommen hat.
