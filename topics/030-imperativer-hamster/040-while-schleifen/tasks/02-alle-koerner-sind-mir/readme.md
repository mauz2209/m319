# Aufgabe – Alle Körner sind mir

Im Territorium liegen mehrere Körner hintereinander.

![Territorium Alle Körner sind mir](../../../../../img/030-040-02-alle-koerner-sind-mir-ter.png)

Der Hamster soll alle Körner einsammeln.

Wie viele Körner auf einem Feld liegen, weiss der Hamster nicht.

## Lernziel

Ich kann mit einer `while`-Schleife alle Körner auf einem Feld aufnehmen, ohne vorher zu wissen, wie viele Körner dort liegen.

## Auftrag

1. Erstelle den Ordner `030-040-02-alle-koerner-sind-mir` im Ordner `/hamster-sim/Programme`.
2. Erstelle das vorgegebene Territorium mit dem Hamster-Simulator und speichere es.
3. Programmiere den Hamster so, dass er alle Körner im Territorium aufnimmt.
4. Prüfe mit `kornDa()`, ob auf dem aktuellen Feld noch ein Korn liegt.
5. Verwende eine `while`-Schleife, um alle Körner auf einem Feld aufzunehmen.
6. Wiederhole diesen Ablauf für alle Felder mit Körnern.
7. Teste dein Programm im Hamster-Simulator.

Dein Programm ist fertig, wenn im Territorium keine Körner mehr liegen.
