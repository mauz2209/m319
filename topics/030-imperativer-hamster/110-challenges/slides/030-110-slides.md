# Challenges

## Jetzt kommt alles zusammen

Ihr kennt inzwischen die wichtigsten Bausteine:

* Funktionen
* Entscheidungen
* Schleifen
* Variablen
* Parameter und Rückgabewerte
* Arrays
* logische Operatoren

Jetzt löst ihr damit **grössere Probleme selbstständig**.

## Macht den Hamster schlau

Die Challenges sind weniger stark vorgegeben.

Euer Programm soll für **unterschiedliche Territorien** funktionieren.

Der Hamster kennt beispielsweise nicht:

* die Anzahl Körner.
* die Länge des Weges.
* die Grösse des Territoriums.

> Was muss der Hamster selbst herausfinden?

## Strukturiert eure Lösung

Zerlegt ein grosses Problem in **kleinere Teilprobleme**.

Verwendet dafür passende Funktionen:

```java
int zaehleKoerner() {
    // ...
}

void baueHaufen() {
    // ...
}
```

Die Namen sollen zeigen, **was die Funktion macht**.

## Namenskonventionen

Variablen und Funktionen schreiben wir in **camelCase**:

```java
int anzahlKoerner = 0;
int groessterHaufen = 0;

int zaehleKoerner() {
    // ...
}
```

Verwendet aussagekräftige Namen.

```text
x                 ✗
anzahlKoerner     ✓
```

## Einrückung

Wir verwenden **4 Leerzeichen** pro Ebene.

```java
if (kornDa()) {
    nimm();

    if (vornFrei()) {
        vor();
    }
} else {
    linksUm();
}
```

Eine saubere Einrückung macht die **Struktur des Programms sichtbar**.

## Ziel

Bei den Challenges geht es nicht nur darum, dass der Hamster am Ende richtig steht.

Eine gute Lösung:

* funktioniert für unterschiedliche Territorien.
* verwendet passende Funktionen.
* verwendet aussagekräftige Namen.
* ist sauber eingerückt.
* ist verständlich aufgebaut.

**Nicht nur lösen – eine gute Lösung entwickeln.**
