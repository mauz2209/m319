# Abbild-Hamster

![](../../../../../img/030-110-04-abbild-hamster-ter.png)

* Der Hamster soll auf der zweiten Zeile das Körnerbild der ersten darlegen.
* Die Körner auf der ersten Zeile sollen liegen bleiben.
* Hat der Hamster die zweite Zeile betreten, darf er nicht mehr zurück.
* Der Hamster kennt die Länge (Anzahl Spalten) nicht.

# Hinwiese

* Mach den Hamster so schlau wie möglich.
* Wende die dir bekannten Konzepte an.
* Halte dich an die Namenskonventionen.
