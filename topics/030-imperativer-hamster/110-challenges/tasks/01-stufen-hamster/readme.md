# Stufen-Hamster

![](../../../../../img/030-110-01-stufen-hamster-ter.png)

* Der Hamster solle alle Körner auf dem Weg zu den Stufen zählen.
* Der Hamster weiss nicht, wie viele Körner es sind.
* Der Hamster soll so viele Stufen erklimmen, wie er Körner gefunden hat.
* Der Hamster darf den Kopf nicht an der Decke anschlagen, falls es mehr Körner als Stufen gibt.

# Hinwiese

* Mach den Hamster so schlau wie möglich.
* Wende die dir bekannten Konzepte an.
* Halte dich an die Namenskonventionen.
