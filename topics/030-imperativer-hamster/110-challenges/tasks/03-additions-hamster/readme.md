# Additons-Hamster

![](../../../../../img/030-110-03-additions-hamster-ter.png)

* Der Hamster soll die Addition durchführen und das Ergebnis mit Körnern hinlegen.
* Die Anzahl Körner auf einem Feld repräsentieren eine Dezimalzahl.

# Hinwiese

* Mach den Hamster so schlau wie möglich.
* Wende die dir bekannten Konzepte an.
* Halte dich an die Namenskonventionen.
