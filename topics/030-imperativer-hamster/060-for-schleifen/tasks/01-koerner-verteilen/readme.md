# Aufgabe – Körner verteilen

Der Hamster hat mehrere Körner im Maul.

Vor ihm liegt ein gerader Weg.

![Territorium Körner verteilen](../../../../../img/030-060-01-koerner-verteilen-ter.png)

Auf jedem freien Feld vor dem Hamster soll er genau ein Korn ablegen.

Die Anzahl Felder ist bekannt.

## Lernziel

Ich kann mit einer `for`-Schleife einen Ablauf eine festgelegte Anzahl Mal wiederholen, um auf mehreren Feldern jeweils ein Korn abzulegen.

## Auftrag

1. Erstelle den Ordner `030-060-01-koerner-verteilen` im Ordner `/hamster-sim/Programme`.
2. Erstelle das vorgegebene Territorium mit dem Hamster-Simulator und speichere es.
3. Speichere die Anzahl der zu belegenden Felder in einer Variable.
4. Verwende eine `for`-Schleife.
5. Der Hamster soll jeweils ein Feld vorwärtsgehen.
6. Auf jedem dieser Felder soll er genau ein Korn ablegen.
7. Schreibe `vor()` und `gib()` nur **einmal** in den Schleifenrumpf.
8. Teste dein Programm im Hamster-Simulator.

Dein Programm ist fertig, wenn auf jedem der sechs Felder vor dem Hamster genau ein Korn liegt.
