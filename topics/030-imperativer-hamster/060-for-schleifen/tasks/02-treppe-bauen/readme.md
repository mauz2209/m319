# Aufgabe – Treppe bauen

Der Hamster hat genügend Körner im Maul.

Vor ihm liegen mehrere leere Felder.

![Territorium Treppe bauen](../../../../../img/030-060-02-treppe-bauen-ter.png)

Der Hamster soll aus den Körnern eine Treppe bauen.

Auf dem ersten Feld legt er **ein Korn** ab.

Auf dem zweiten Feld legt er **zwei Körner** ab.

Auf dem dritten Feld legt er **drei Körner** ab.

So geht es weiter, bis die Treppe vollständig ist.

## Lernziel

Ich kann die Zählvariable einer `for`-Schleife verwenden, um auf aufeinanderfolgenden Feldern eine zunehmende Anzahl Körner abzulegen.

## Auftrag

1. Erstelle den Ordner `030-060-02-treppe-bauen` im Ordner `/hamster-sim/Programme`.
2. Erstelle das vorgegebene Territorium mit dem Hamster-Simulator und speichere es.
3. Programmiere den Hamster so, dass er eine Treppe aus Körnern baut.
4. Die Treppe besteht aus sechs Feldern.
5. Lege auf dem ersten Feld ein Korn ab.
6. Lege auf dem zweiten Feld zwei Körner ab.
7. Fahre nach diesem Muster bis zum sechsten Feld weiter.
8. Verwende eine `for`-Schleife für die sechs Felder.
9. Verwende die Zählvariable der `for`-Schleife, um zu bestimmen, wie viele Körner auf einem Feld abgelegt werden.
10. Verwende eine weitere `for`-Schleife, um die Körner auf dem jeweiligen Feld abzulegen.
11. Teste dein Programm im Hamster-Simulator.

Dein Programm ist fertig, wenn auf den sechs Feldern nacheinander `1`, `2`, `3`, `4`, `5` und `6` Körner liegen.
