# Aufgabe – Kornquadrat

Der Hamster hat genügend Körner im Maul.

Er soll ein Quadrat aus Körnern legen.

![Territorium Kornquadrat](../../../../../img/030-060-03-kornquadrat-ter.png)

Das Quadrat hat eine Seitenlänge von sechs Feldern.

Auf jedes Feld des Quadrats soll der Hamster ein Korn legen.

## Lernziel

Ich kann verschachtelte `for`-Schleifen verwenden, um vier gleich lange Seiten eines Quadrats abzulaufen und dabei auf jedem Feld ein Korn abzulegen.

## Auftrag

1. Erstelle den Ordner `030-060-03-kornquadrat` im Ordner `/hamster-sim/Programme`.
2. Erstelle das vorgegebene Territorium mit dem Hamster-Simulator und speichere es.
3. Speichere die Seitenlänge des Quadrats in einer Variable.
4. Programmiere den Hamster so, dass er ein Quadrat aus Körnern legt.
5. Verwende eine `for`-Schleife für die vier Seiten des Quadrats.
6. Verwende innerhalb dieser Schleife eine weitere `for`-Schleife für die einzelnen Felder einer Seite.
7. Lege auf jedem Feld des Quadrats genau ein Korn ab.
8. Drehe den Hamster nach jeder Seite um 90°.
9. Verwende eine eigene Funktion `rechtsUm()` oder `linksUm()`, um die Richtung zu wechseln.
10. Teste dein Programm im Hamster-Simulator.

Dein Programm ist fertig, wenn die Körner ein geschlossenes Quadrat mit einer Seitenlänge von sechs Feldern bilden.

Der Hamster soll danach wieder auf seinem Startfeld stehen.
