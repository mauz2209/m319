# For-Schleifen

## Eine bekannte Anzahl Wiederholungen

Der Hamster soll genau **5 Schritte** laufen.

Mit `while`:

```java
int anzahl = 0;

while (anzahl < 5) {
    vor();
    anzahl = anzahl + 1;
}
```

Für solche Wiederholungen gibt es eine kompaktere Schreibweise.

## Die `for`-Schleife

```java
for (int i = 0; i < 5; i++) {
    vor();
}
```

Der Hamster führt `vor()` genau **5-mal** aus.

Die Variable `i` zählt die Durchläufe.

## Aufbau

Eine `for`-Schleife besteht aus drei Teilen:

```java
for (int i = 0; i < 5; i++) {
    vor();
}
```

```text
int i = 0   Startwert
i < 5       Bedingung
i++         Veränderung
```

Nach jedem Durchlauf wird `i` um `1` erhöht.

## Was passiert?

```java
for (int i = 0; i < 5; i++) {
    vor();
}
```

```text
i:   0   1   2   3   4   5
     ↓   ↓   ↓   ↓   ↓
    vor vor vor vor vor  Ende
```

Die Schleife wird **5-mal** ausgeführt.

## `while` oder `for`?

`while` verwenden wir, wenn wir vorher **nicht wissen**, wie viele Wiederholungen notwendig sind:

```java
while (vornFrei()) {
    vor();
}
```

`for` verwenden wir, wenn die **Anzahl der Wiederholungen bekannt** ist:

```java
for (int i = 0; i < 5; i++) {
    vor();
}
```

## Merken

Eine `for`-Schleife eignet sich für eine bekannte Anzahl Wiederholungen.

```java
for (int i = 0; i < anzahl; i++) {
    // Anweisungen
}
```

**`for` verbindet Zählvariable, Bedingung und Veränderung in einer Zeile.**
