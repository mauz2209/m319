# Eindimensionale Arrays

## Mehrere Werte speichern

Eine Variable speichert **einen Wert**:

```java
int anzahl = 3;
```

Was machen wir, wenn wir mehrere zusammengehörende Werte speichern möchten?

```text
3   7   2   5   4
```

Dafür verwenden wir ein **Array**.

## Ein Array

Ein Array speichert mehrere Werte desselben Datentyps.

```java
int[] koerner = {3, 7, 2, 5, 4};
```

```text
Wert:    3   7   2   5   4
Index:   0   1   2   3   4
```

Jedes Element besitzt einen **Index**.

Der erste Index ist immer `0`.

## Auf ein Element zugreifen

Über den Index greifen wir auf ein einzelnes Element zu:

```java
int[] koerner = {3, 7, 2, 5, 4};

int anzahl = koerner[2];
```

`koerner[2]` hat den Wert:

```text
2
```

Der Index bezeichnet die **Position**, nicht den Wert.

## Ein Element verändern

Ein Element kann wie eine Variable verändert werden:

```java
koerner[2] = 8;
```

Vorher:

```text
3   7   2   5   4
```

Nachher:

```text
3   7   8   5   4
```

## Länge eines Arrays

Die Anzahl der Elemente erhalten wir mit:

```java
koerner.length
```

Für:

```java
int[] koerner = {3, 7, 2, 5, 4};
```

gilt:

```text
koerner.length = 5
```

Die gültigen Indizes sind damit `0` bis `4`.

## Array durchlaufen

Arrays und `for`-Schleifen passen gut zusammen:

```java
for (int i = 0; i < koerner.length; i++) {
    int anzahl = koerner[i];
}
```

`i` nimmt nacheinander die Indizes an:

```text
0 → 1 → 2 → 3 → 4
```

So können wir jedes Element des Arrays verarbeiten.

## Merken

Ein Array speichert **mehrere Werte desselben Datentyps**.

```java
int[] koerner = {3, 7, 2, 5, 4};
```

```text
Wert:    3   7   2   5   4
Index:   0   1   2   3   4
```

* Der erste Index ist `0`.
* Mit `[index]` greifen wir auf ein Element zu.
* `.length` liefert die Anzahl der Elemente.
* Mit einer `for`-Schleife können wir das ganze Array durchlaufen.
