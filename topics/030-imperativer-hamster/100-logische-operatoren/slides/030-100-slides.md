# Logische Operatoren

## Mehrere Bedingungen

Bisher haben wir einzelne Bedingungen verwendet:

```java
if (vornFrei()) {
    vor();
}
```

Manchmal hängt eine Entscheidung von **mehreren Bedingungen** ab.

Dafür verwenden wir logische Operatoren.

## Drei logische Operatoren

| Operator | Bedeutung |
|---|---|
| `&&` | AND – und |
| `||` | OR – oder |
| `!` | NOT – nicht |

Das Ergebnis ist immer:

```text
true
```

oder:

```text
false
```

## AND – `&&`

Bei AND müssen **beide Bedingungen** `true` sein.

```java
if (vornFrei() && kornDa()) {
    vor();
}
```

```text
A       B       A && B

false   false   false
false   true    false
true    false   false
true    true    true
```

## OR – `||`

Bei OR muss **mindestens eine Bedingung** `true` sein.

```java
if (kornDa() || maulLeer()) {
    vor();
}
```

```text
A       B       A || B

false   false   false
false   true    true
true    false   true
true    true    true
```

## NOT – `!`

NOT kehrt einen Wahrheitswert um.

```java
if (!vornFrei()) {
    linksUm();
}
```

```text
A       !A

false   true
true    false
```

`!vornFrei()` bedeutet:

**Vorne ist nicht frei.**

## Operatoren kombinieren

Wir können die Operatoren kombinieren:

```java
if (!maulLeer() && vornFrei()) {
    vor();
}
```

Der Hamster geht vorwärts, wenn:

* sein Maul **nicht leer** ist.
* **und** das Feld vor ihm frei ist.

## Präzedenz

Bei mehreren Operatoren gilt eine feste Reihenfolge:

```text
1.  ()
2.  !
3.  &&
4.  ||
```

Merke:

> **Klammer vor NOT vor AND vor OR.**

## Klammern

Klammern können die Bedeutung verändern.

```java
kornDa() || maulLeer() && vornFrei()
```

ist nicht dasselbe wie:

```java
(kornDa() || maulLeer()) && vornFrei()
```

**Klammern machen komplexe Bedingungen zudem besser lesbar.**

## Merken

```text
&&    beide müssen true sein

||    mindestens eine muss true sein

!     kehrt true und false um
```

Für die Reihenfolge gilt:

> **Klammer vor NOT vor AND vor OR.**

Damit können wir mehrere Informationen zu **einer Bedingung** verbinden.
