# Entscheidungen

## Bisher

Bisher führt der Hamster alle Anweisungen der Reihe nach aus.

```java
vor();
vor();
linksUm();
vor();
```

Aber was soll der Hamster tun, wenn die richtige Aktion von seiner Umgebung abhängt?

## Die Umgebung prüfen

Der Hamster kann Fragen über seine Umgebung beantworten:

```java
vornFrei()
kornDa()
maulLeer()
```

Das Ergebnis ist immer:

```text
true
```

oder:

```text
false
```

## `if`

Mit `if` führen wir Anweisungen nur aus, wenn eine Bedingung erfüllt ist.

```java
if (kornDa()) {
    nimm();
}
```

Der Hamster nimmt das Korn nur, wenn auf seinem Feld ein Korn liegt.

## `if` und `else`

Manchmal gibt es zwei Möglichkeiten:

```java
if (kornDa()) {
    nimm();
} else {
    vor();
}
```

Ist die Bedingung `true`, wird der erste Block ausgeführt.

Ist sie `false`, wird der `else`-Block ausgeführt.

## Entscheidungen im Programm

```text
          kornDa()?
          /       \
       true       false
        /           \
     nimm()         vor()
```

Nach der Entscheidung läuft das Programm weiter.

## Bedingungen und Funktionen

Entscheidungen können wir mit eigenen Funktionen kombinieren:

```java
if (kornDa()) {
    linksUm();
} else {
    rechtsUm();
}
```

`rechtsUm()` haben wir selbst definiert.

So können wir komplexeres Verhalten aus einfachen Bausteinen zusammensetzen.

## Merken

Mit Bedingungen kann ein Programm auf unterschiedliche Situationen reagieren.

```java
if (Bedingung) {
    // Bedingung ist true
} else {
    // Bedingung ist false
}
```

**Das Programm entscheidet anhand des aktuellen Zustands, welche Anweisungen ausgeführt werden.**
