# Aufgabe – RechtsUmHamster

Bisher verwendest du Objekte der Klasse `Hamster`.

Nun erstellst du eine **eigene Hamster-Klasse**.

Deine Klasse soll einen Hamster um die Fähigkeit `rechtsUm()` erweitern.

## Lernziel

Ich kann eine eigene Klasse `RechtsUmHamster` erstellen, die Klasse `Hamster` erweitern, eine eigene Methode `rechtsUm()` implementieren und ein Objekt dieser Klasse verwenden.

## Auftrag

1. Erstelle für die Aufgabe einen eigenen Ordner nach Vorgabe.
2. Erstelle die Klasse `RechtsUmHamster`.
3. `RechtsUmHamster` soll die Klasse `Hamster` erweitern.
4. Erstelle in `RechtsUmHamster` die Methode `rechtsUm()`.
5. Implementiere `rechtsUm()` mit den bereits vorhandenen Methoden des Hamsters.
6. Erstelle in deinem Programm ein Objekt der Klasse `RechtsUmHamster`.
7. Verwende die neue Methode `rechtsUm()`, um den Hamster nach rechts zu drehen.
8. Kombiniere `rechtsUm()` mit weiteren Hamster-Methoden wie `vor()`, `nimm()` oder `gib()`.
9. Teste dein Programm im Hamster-Simulator.

Deine Aufgabe ist fertig, wenn du ein Objekt der Klasse `RechtsUmHamster` erzeugen und darauf `rechtsUm()` aufrufen kannst.

~~~java
RechtsUmHamster hamster = new RechtsUmHamster();

// ...

hamster.rechtsUm();
~~~
