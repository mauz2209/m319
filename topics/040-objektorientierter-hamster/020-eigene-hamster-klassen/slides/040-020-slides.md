# Eigene Hamster-Klassen

## Bisher

Bisher erzeugen wir Objekte der vorhandenen Klasse `Hamster`:

```java
Hamster paul = new Hamster();

paul.vor();
paul.linksUm();
```

Jetzt erstellen wir **eigene Hamster-Klassen**.

Damit können wir Hamster um eigene Fähigkeiten erweitern.

## Eine eigene Klasse

Unsere Klasse kann `Hamster` erweitern:

```java
class RechtsUmHamster extends Hamster {

}
```

`extends Hamster` bedeutet:

> `RechtsUmHamster` erweitert die Klasse `Hamster`.

## Vorhandene Fähigkeiten

Ein `RechtsUmHamster` übernimmt die Fähigkeiten von `Hamster`.

```java
RechtsUmHamster paul = new RechtsUmHamster();

paul.vor();
paul.linksUm();
paul.nimm();
paul.gib();
```

Wir müssen diese Methoden nicht selbst neu schreiben.

## Neue Fähigkeiten

Wir können zusätzliche Methoden ergänzen:

```java
class RechtsUmHamster extends Hamster {

    void rechtsUm() {
        linksUm();
        linksUm();
        linksUm();
    }
}
```

Unsere Klasse erweitert damit die Fähigkeiten eines normalen Hamsters.

## Die neue Klasse verwenden

Jetzt erzeugen wir ein Objekt unserer eigenen Klasse:

```java
RechtsUmHamster paul = new RechtsUmHamster();
```

Danach kann `paul` auch unsere neue Methode verwenden:

```java
paul.rechtsUm();
```

## Vererbung

```text
        Hamster
           ↑
           │ extends
           │
   RechtsUmHamster
```

`RechtsUmHamster` erhält die vorhandenen Fähigkeiten von `Hamster`.

Zusätzlich kann die Klasse **eigene Fähigkeiten** definieren.

## Eigene Konstruktoren

Auch unsere Klasse kann einen Konstruktor besitzen:

```java
class SuperHamster extends Hamster {

    SuperHamster(/* Parameter */) {
        super(/* Argumente */);
    }
}
```

`super(...)` ruft den Konstruktor der Klasse `Hamster` auf.

## Merken

Mit `extends` bauen wir auf einer vorhandenen Klasse auf:

```java
class RechtsUmHamster extends Hamster {
    // zusätzliche Fähigkeiten
}
```

Die neue Klasse:

* übernimmt vorhandene Methoden.
* kann neue Methoden erhalten.
* kann einen eigenen Konstruktor besitzen.

**Wir verwenden vorhandenen Code und erweitern ihn.**
