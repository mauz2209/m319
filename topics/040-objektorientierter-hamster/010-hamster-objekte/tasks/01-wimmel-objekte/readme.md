# Einführung in Klassen und Objekte
## Merke

Objektorientierte Programmierung ist in erster Linie eine **Denkweise**.

## Gruppenarbeit

1. Gruppen bilden (2 - 4 Lernende), Arbeitszeit ca. 15 Minuten
2. Jede Gruppe sucht sich ein Objekt aus dem Wimmelbild aus.
3. Jede Gruppe beschreibt das Objekt auf einem **Flipchart** im Sinne von:
    * **Eigenschaften:** Dinge, die das Objekt **weiss** oder **kennt**.
    * **Verhalten:**  Dinge, die das Objekt **tut** oder **kann**.
4. Ergebnisse im Plenum vortragen und besprechen.

![Wimmelbild mit Objekten](../../../../../img/040-010-01-wimmel-objekte.png)

## Nacharbeit - Lehrperson

* Erkenntnisse auf den Hamster übertragen. Was **weiss** oder **kennt** der Hamster und was **kann** oder **tut** er?
    * **wissen / kennen**: Eigenschaften oder Instanzvariablen.
    * **können / tun**: Funktionen oder neu Methoden.
