# Hamster-Objekte

![](../../../../../img/040-010-02-hamster-objekte-ter.png)

* Erzeuge 7 Hamster.
* Die Hamster finden auf ihrer Kachel Körner.
* Die Hamster sollen so viele Schritte gehen, wie sie Körner gefunden haben.
* Die Hamster dürfen nicht gegen eine Mauer laufen.

# Hinwiese

* Erzeuge die Hamster mit `new`
* Gib den Hamstern einen Namen.
* Initialisiere die Hamster mit `init`.
* Denke daran, dass du den Funktionen (Methoden) den Namen des Hamsters voranstellen musst.
