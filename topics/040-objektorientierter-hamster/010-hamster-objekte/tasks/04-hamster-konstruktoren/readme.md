# Hamster-Konstruktoren

* Im Hamster-Simulator, öffne die Hamster-API mit `Hilfe/Hamster-API`.
* Schau dir den Abschnitt `Constructor Detail` genau an.
* Ein Konstuktor ist eine spezielle Methode, die den Hamster erzeugt, wenn du `new` verwendest.
* Schreibe ein objektorientiertes Hamsterprogramm und erzeuge 4 Hamster. Verwende dabei jeden Konstruktor genau ein mal.
