# Objektorientierter Hamster

## Bisher

Bisher gab es **einen Hamster**.

```java
vor();
linksUm();
nimm();
gib();
```

Die Befehle bezogen sich immer auf diesen Hamster.

Jetzt können wir **mehrere Hamster** verwenden.

## Hamster erzeugen

Einen neuen Hamster erzeugen wir mit `new`:

```java
Hamster paul = new Hamster();
```

`Hamster` ist der **Datentyp**.

`paul` ist eine Variable.

`new Hamster()` erzeugt ein neues **Hamster-Objekt**.

## Befehle an ein Objekt senden

Jetzt müssen wir angeben, **welcher Hamster** etwas tun soll.

```java
paul.vor();
paul.linksUm();
paul.nimm();
```

Ein zweiter Hamster kann unabhängig davon handeln:

```java
anna.vor();
```

Der Punkt verbindet **Objekt und Befehl**.

## Mehrere Hamster

```java
Hamster paul = new Hamster();
Hamster anna = new Hamster();
```

Wir haben jetzt zwei verschiedene Objekte:

```text
paul ──────► Hamster

anna ──────► Hamster
```

Beide sind Hamster.

Aber es sind **zwei unterschiedliche Hamster-Objekte**.

## Objekt und Zustand

Jeder Hamster besitzt seinen eigenen **Zustand**.

* Position
* Blickrichtung
* Körner im Maul

Wenn sich `paul` bewegt:

```java
paul.vor();
```

ändert sich der Zustand von `paul`. Der Zustand von `anna` bleibt unverändert.

## Merken

Mit Objekten können mehrere Hamster unabhängig voneinander existieren.

```java
Hamster paul = new Hamster();

paul.vor();
```

```text
Hamster       → Typ
paul          → Variable
new Hamster() → neues Objekt
paul.vor()    → Befehl an das Objekt
```

**Ein Objekt besitzt einen eigenen Zustand und kann Befehle ausführen.**
