# Codevogel

[Codevogel](https://codevogel.ch) ist unsere GitLab-Plattform für den Unterricht.

Wir verwenden Codevogel, um Programmcode und andere Dateien mit **Git** zu verwalten.

Du wirst Codevogel unter anderem verwenden, um:

- Projekte und Aufgaben zu erhalten.
- deinen Programmcode zu speichern.
- Änderungen mit Git zu versionieren.
- deinen aktuellen Stand auf den Server zu übertragen.
- mit anderen an Projekten zusammenzuarbeiten.
- Abgaben einzureichen.

Dein Benutzerkonto begleitet dich während des Unterrichts.
