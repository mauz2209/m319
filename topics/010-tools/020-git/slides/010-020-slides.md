# Git

## Versionsverwaltung

Git ist ein **Versionsverwaltungssystem**.

Wir verwenden Git, um:

* Änderungen an unseren Programmen zu speichern.
* die Entwicklung eines Programms nachzuvollziehen.
* Lösungen auf Codevogel abzugeben.

## Repository

Ein **Repository** ist ein von Git verwaltetes Projekt.

Wir arbeiten mit zwei Kopien:

* **Local Repository** auf deinem Computer.
* **Remote Repository** auf Codevogel.

![Local und Remote Repository](../../../../img/010-020-local-remote-repository.png)

## Local und Remote

Das Repository wird zuerst von Codevogel **geklont**:

```text
Remote Repository
       │
       │ clone
       ▼
Local Repository
```

Danach arbeitest du hauptsächlich im **Local Repository**.

Mit `push` überträgst du deine Commits auf Codevogel.

# Branches

## Dein eigener Branch

Der Branch `main` enthält die Unterlagen der Lehrperson.

Du arbeitest in deinem **eigenen Branch**.

```text
main
│
├── schneller
├── mueller
└── meier
```

So können alle im gleichen Repository arbeiten.

# Änderungen speichern

## Der wichtigste Git-Ablauf

```text
Dateien ändern
      │
      ▼
   git add
      │
      ▼
  git commit
      │
      ▼
   git push
      │
      ▼
  Codevogel
```

## Commit

Ein **Commit** speichert einen Stand deiner Änderungen.

```bash
git add .
git commit -m "solution: 030-010-01-geh-zum-korn"
```

Die Commit-Message beschreibt die Änderung.

Für Aufgaben verwenden wir die vorgegebene Nomenklatur.

## Push

Ein Commit ist zunächst nur in deinem lokalen Repository.

```bash
git push
```

`push` überträgt deine Commits auf Codevogel.

Danach kontrollierst du deine Abgabe auf Codevogel.

# Unterlagen aktualisieren

## Änderungen aus `main` übernehmen

Neue Unterlagen übernimmst du in deinen eigenen Branch:

```bash
git pull --rebase origin main
```

Danach überträgst du deinen aktualisierten Branch:

```bash
git push --force-with-lease origin [nachname]
```

Führe dies nur aus, wenn die Lehrperson dich dazu auffordert.

# Git

## Die wichtigsten Befehle

| Befehl | Bedeutung |
| --- | --- |
| `git status` | Zustand anzeigen |
| `git branch` | Branch anzeigen |
| `git add` | Änderungen vormerken |
| `git commit` | Änderungen speichern |
| `git push` | Commits auf Codevogel übertragen |
| `git pull` | Änderungen herunterladen |

## Unser Workflow

```text
              Codevogel
                  │
                clone
                  ▼
            dein Computer
                  │
          Aufgabe bearbeiten
                  │
             git add
                  │
            git commit
                  │
             git push
                  ▼
              Codevogel
```

**Du arbeitest immer in deinem eigenen Branch.**
