# Fehler im Programm finden und beheben

## Ziel

* Du kannst ein Programm mit dem Debugger schrittweise ausführen.

## Auftrag

* Erstelle ein Programm, welches den Hamster nacheinander drei Schritte nach vorne laufen lässt.
  ```java
  void main() {
    vor();
    vor();
    vor();
  }
  ```
* Lade das Territorium `ErstesTerritorium`.
* Aktiviere den Debugger und starte das Programm.
* Pausiere das Programm sofort nach dem Start.
* Führe das Programm schrittweise aus und beobachte die Hamsterbewegungen.
* Beantworte die Frage: Führt das Programm im gegebenen Territorium zu einem Fehler? Nach welchem Schritt?

## Resultat

* Ein Programm, welches den Hamster drei Schritte nach vorne laufen lässt.
* Das Territorium `ErstesTerritorium` ist geladen.
* Du kannst den Fehler im Programm erkennen und erklären.
