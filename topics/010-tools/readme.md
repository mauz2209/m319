# Werkzeuge

In diesem Modul verwenden wir verschiedene Werkzeuge zum Programmieren und zum Verwalten unserer Arbeit.

Du richtest diese Werkzeuge zu Beginn des Moduls ein.

Danach verwenden wir sie während des ganzen Moduls.

## Codevogel

Codevogel ist unsere GitLab-Umgebung.

Dort findest du das Projekt zum Modul.

Du verwendest Codevogel auch, um deine eigenen Lösungen abzugeben.

➡️ [Codevogel](010-codevogel/readme.md)

## Git

Mit Git verwalten wir den Programmcode und unsere Änderungen.

Du lernst unter anderem:

- ein Projekt zu klonen,
- mit Verzeichnissen und Pfaden zu arbeiten,
- einen eigenen Branch zu erstellen,
- Änderungen mit Commits zu speichern,
- deine Lösungen auf Codevogel zu übertragen,
- neue Unterlagen aus `main` zu übernehmen.

➡️ [Git](020-git/readme.md)

## Markdown

Viele Unterlagen in diesem Projekt sind in Markdown geschrieben.

Auch die Datei, die du gerade liest, ist eine Markdown-Datei.

Du lernst die wichtigsten Elemente kennen und erstellst selbst eine Markdown-Datei.

➡️ [Markdown](030-markdown/readme.md)

## Java

Unsere Programme schreiben wir in Java.

Du richtest Java auf deinem Computer ein und prüfst, ob die Installation funktioniert.

➡️ [Java](040-java/readme.md)

## Hamster-Simulator

Mit dem Hamster-Simulator lernen wir die Grundlagen der Programmierung.

Der Hamster bewegt sich durch ein Territorium und führt deine Java-Befehle aus.

So kannst du direkt beobachten, was dein Programm macht.

➡️ [Hamster-Simulator](050-hamster-simulator/readme.md)

## Visual Studio Code

Visual Studio Code ist unser Editor.

Du verwendest ihn zum Bearbeiten von Programmcode und anderen Dateien im Projekt.

➡️ [Visual Studio Code](060-visual-studio-code/readme.md)
