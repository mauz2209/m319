# Markdown
## Text einfach formatieren

Markdown ist eine einfache **Auszeichnungssprache für Text**.

Eine Markdown-Datei ist eine normale Textdatei.

```text
readme.md
```

Codevogel stellt Markdown-Dateien automatisch formatiert dar.

# Markdown
## Überschriften

Überschriften werden mit `#` ausgezeichnet.

```markdown
# Überschrift 1

## Überschrift 2

### Überschrift 3
```

Je mehr `#` du verwendest, desto kleiner ist die Überschrift.

# Markdown
## Text hervorheben

```markdown
Das ist **fett**.

Das ist *kursiv*.

Das ist `Code`.
```

Ergebnis:

Das ist **fett**.

Das ist *kursiv*.

Das ist `Code`.

# Markdown
## Listen

Ungeordnete Liste:

```markdown
- Java
- Python
- JavaScript
```

Nummerierte Liste:

```markdown
1. Programmieren lernen
2. Erfahrungen sammeln
3. Lehrabschluss bestehen
```

# Markdown
## Links

Ein Link besteht aus einem Text und einer Adresse.

```markdown
[Codevogel](https://codevogel.ch)
```

Ergebnis:

[Codevogel](https://codevogel.ch)

# Markdown
## Bilder

Bilder werden ähnlich wie Links eingebunden.

Vor der eckigen Klammer steht zusätzlich ein `!`.

```markdown
![Mein Profilbild](img/profilbild.jpg)
```

Wir verwenden **relative Pfade**.

Der Pfad beginnt beim Verzeichnis der Markdown-Datei.

# Markdown
## Codeblöcke

Code wird zwischen drei Backticks geschrieben.

~~~markdown
```java
System.out.println("Hallo Welt!");
```
~~~

Die Sprache hinter den ersten Backticks ermöglicht **Syntax Highlighting**.

Ergebnis:

```java
System.out.println("Hallo Welt!");
```

# Markdown
## Die wichtigsten Elemente

| Markdown | Bedeutung |
| --- | --- |
| `# Titel` | Überschrift |
| `**Text**` | fett |
| `*Text*` | kursiv |
| `` `Code` `` | Code im Text |
| `- Element` | Liste |
| `[Text](URL)` | Link |
| `![Text](Pfad)` | Bild |
| ` ```java ` | Codeblock |

# Markdown
## Markdown schreiben

Markdown bleibt auch als Text gut lesbar.

```markdown
# Mein Steckbrief

## Über mich

Ich heisse **Max Muster**.

Meine Hobbys sind:

- Programmieren
- Mountainbike
- Gaming

Mehr über meine Schule:
[GBC](https://www.gbchur.ch)
```

Codevogel übernimmt die **Darstellung**.
