# Was ist programmieren?
## Ziel

* Du kannst Markdown-Dateien mit VS Code bearbeiten und anzeigen.

## Auftrag

* Installiere VS Code gemäss dem Script.
* Installiere die Erweiterung "Markdown All in One" in VS Code.
* Öffne dein Git-Repo in VS Code: File -> Open Folder...
* Zeige die Vorschau einer Markdown-Datei an.

## Resultat

* Du hast VS Code installiert und kannst Markdown-Dateien bearbeiten und anzeigen.

## Form

* Einzelarbeit

## Zeit

* 15 Minuten

## Auswertung

* Selbstständig
