# Visual Studio Code

## Lernziele

* Ich kann Visual Studio Code auf meinem Computer installieren und starten.
* Ich kann Visual Studio Code nutzen, um Markdown-Dateien zu erstellen, zu bearbeiten und anzuzeigen.


## Themen
* Kennenlernen von Visual Studio Code als Editor.
* Bearbeiten von Markdown-Dateien in Visual Studio Code.

## Übersicht

Visual Studio Code (kurz: VS Code) ist ein **Editor**. Ein Editor ist eine Applikation, mit der du Textdateien erstellen und bearbeiten kannst.
Als Informatiker wirst du häufig mit Textdateien arbeiten und diese bearbeiten müssen:
- Textdateien sind die Grundlage von Programmen (Quellcode)
- Konfigurationsdateien sind speziell formatierte Textdateien
- *Auszeichnungsprachen* (markup languages) wie zum Beispiel Markdown bestehen aus Textdateien

Wir nutzen VS Code, um **Markdown-Dateien** zu erstellen, zu bearbeiten und anzuzeigen.

## VS Code installieren
1. Lade die Installationsdatei von der offiziellen Webseite herunter: [https://code.visualstudio.com/](https://code.visualstudio.com/)
2. Starte die Installationsdatei und folge den Anweisungen des Installationsassistenten.
3. Starte VS Code nach der Installation.
4. Installiere die Erweiterungen für Markdown, um die Bearbeitung und Vorschau von Markdown-Dateien zu erleichtern. Meine Empfehlung: "Markdown All in One".

## Markdown-Dateien in VS Code bearbeiten
Du kannst Markdown-Dateien in VS Code öffnen, bearbeiten, speichern. Was kann nun aber VS Code mehr als ein normaler Texteditor?  
Dank das Markdown-Plugins kann VS Code erkennen, dass eine Datei markdown enthält. Das Wichtigste dabei: VS Code kann das formatierte Markdown anzeigen, so wie es später in GitLab (codevogel) angezeigt wird.  
Drücke dazu die Tastenkombination `Strg + Shift + P`, um die Command Palette zu öffnen. Nun gib den Befehl `Markdown: Open Preview` ein. Das formatierte Markdown wird nun in einem neuen Fenster angezeigt.
