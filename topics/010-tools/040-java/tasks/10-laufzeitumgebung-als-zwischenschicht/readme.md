# Programmiersprachen mit *Runtime*
## Ziel

* Du kannst je mindestens ein Beispiel einer Programmiersprache nennen, die eine Runtime verwendet oder die direkt vom Betriebssystem ausgeführt wird.

## Auftrag

Du hast im Unterricht gelernt, dass Java eine Programmiersprache ist, die eine Runtime benötigt. Lies dazu auch nochmal das [Script](../script/README.md).  
Recherchiere nun im Internet, welche Programmiersprachen eine Runtime benötigen und welche direkt vom Betriebssystem ausgeführt werden. Schreib für dich folgende Informationen auf:
* Name der Programmiersprache
* Ob die Programmiersprache eine Runtime benötigt oder direkt vom Betriebssystem ausgeführt wird.
* Wenn die Programmiersprache eine Runtime benötigt, nenne auch den Namen der Runtime.

## Resultat

* Eine Tabelle mit den recherchierten Informationen zu Programmiersprachen und deren Runtimes.
