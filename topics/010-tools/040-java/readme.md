# Java (Programmiersprache und Laufzeitumgebung)

## Lernziele

* Ich kann in meinen eigenen Worten erklären, warum eine Java-Applikation eine Java-Laufzeitumgebung benötigt.
* Ich kann eine Java-Laufzeitumgebung auf meinem Computer installieren.

## Themen
* Installation einer Java-Laufzeitumgebung

## Übersicht
Java ist in erster Linie eine **Programmiersprache**. Als Programmierer schreibst du Java-Quellcode, um ein Programm zu erstellen.  
Um das in Java geschriebene Programm auf einem Computer auszuführen, brauchst du eine **Java-Laufzeitumgebung** (Java Runtime Environment, JRE). Java-Programme werden nämlich nicht direkt vom Betriebssystem ausgeführt.  
Die Java-Runtime dient als Zwischenschicht zwischen dem Programm und dem Betriebssystem.  

![Java: 3-Schichten-Modell](../../../../resources/java-runtime-3-layers.svg)

Wir nutzen in diesem Modul den *Hamster-Simulator*, der in Java geschrieben ist. Um den Hamster-Simulator auf deinem Computer auszuführen, musst du daher eine Java-Laufzeitumgebung installieren.  

Übrigens: Der Name Java ist eine Anspielung auf Kaffee (Java als Slangwort für Kaffee) und soll Energie sowie Verlässlichkeit symbolisieren.
